# Polaroid Diary

> 一个 Trae AI Skill，从照片中提取人物/物体的局部特写，生成干净柔和的四宫格拍立得日记海报

## 功能特点

- 智能特写提取：自动识别人像的眼睛、嘴唇、耳朵、手部、脚踝等细节部位，四个特写景别富有节奏变化
- 手绘涂鸦呼应：每个特写搭配主题相关的奶白色铅笔手绘线条（眼睛配星芒星座、耳朵配时钟招牌效果等）
- 撕拉片质感：干净柔和低饱和度的现代撕拉片色调，无浓重旧化泛黄
- 手写英文短句：底部边框儿童笨拙风格的细铅笔手写英文
- 纯白色底：纯净白纸背景，干净清透
- 整齐排版：严格对齐的2乘2网格，拍立得横平竖直无旋转

## 安装

### 方式一：直接复制到项目

```bash
# 进入你的项目目录
cd your-project

# 创建 skills 目录（如果不存在）
mkdir -p .trae/skills

# 克隆并复制 skill
git clone https://github.com/1NWZ/polaroid-diary.git
cp -r polaroid-diary/.trae/skills/polaroid-diary/ .trae/skills/

# 清理临时文件
rm -rf polaroid-diary
```

### 方式二：手动添加

1. 在你的项目中创建目录 `.trae/skills/polaroid-diary/`
2. 将本仓库的 [SKILL.md](.trae/skills/polaroid-diary/SKILL.md) 复制到该目录

## 使用方法

在 Trae 中上传一张图片，然后说：

```
"用 polaroid-diary 生成拍立得日记"
"帮我生成这张照片的特写四宫格"
"生成拍立得风格的局部特写手账"
```

Skill 会自动：
1. 分析图片，选择4个有景别差异的特写部位
2. 为每个特写设计呼应主题的手绘涂鸦（耳朵会自动生成招牌时钟效果）
3. 统一柔和低饱和度色调调色
4. 生成整齐对齐的2乘2四宫格拍立得排版

## 核心美学原则

- 色彩：柔和低饱和度撕拉片色调，肤色自然干净，禁止浓重复古黄
- 线条：纤细、连贯、儿童笨拙手写感，轻微抖动，禁止干净矢量线，禁止粗线
- 背景：纯白色纸张纹理，禁止米色、淡黄色、奶油色
- 排版：严格横平竖直对齐，边框无旋转，单张内容可带自然角度
- 景别：四个特写有明显景别差异，形成节奏
- 阴影：极淡柔和阴影或平贴，禁止浓重深色投影
- 氛围：安静、亲密、柔和、慵懒的私人日记感

## 注意事项

- 建议使用光线柔和的照片效果最佳
- 人像照片建议面部清晰可见，便于提取细节
- 输出为正方形高清图，适合社交媒体分享
