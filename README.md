# Polaroid Diary

> 一个 Trae AI Skill，从照片中提取人物/物体的局部特写，生成干净柔和、极简点缀的四宫格拍立得日记海报

## 功能特点

- 智能特写提取：自动识别人像的眼睛、嘴唇、耳朵、手部、脚踝等细节部位，四个特写景别富有节奏变化
- 极简手绘涂鸦：每个特写只在关键位置画1-3个元素作为画龙点睛的点缀，大面积留白，禁止铺满画面
- 招牌耳朵时钟：耳朵特写自动在耳朵轮廓内绘制钟面效果，诗意且逻辑自洽
- 真实铅笔手写：底部边框为自然潦草的铅笔手写英文，有连笔和大小变化，像真人随手书写
- 撕拉片质感：干净柔和低饱和度的现代撕拉片色调，无浓重旧化泛黄
- 纯白色底：纯净白纸背景，干净清透
- 整齐排版：严格对齐的2乘2网格，拍立得边框横平竖直无旋转

## 安装

### 方式一：直接复制到项目

```bash
# 进入你的项目目录
cd your-project

# 创建 skills 目录（如果不存在）
mkdir -p .trae/skills

# 克隆并复制 skill
git clone https://github.com/1NWZ/polaroid-diary.git
cp -r polaroid-diary/.trae/skills/polaroid-diary/ .trae/skills/

# 清理临时文件
rm -rf polaroid-diary
```

### 方式二：手动添加

1. 在你的项目中创建目录 `.trae/skills/polaroid-diary/`
2. 将本仓库的 [SKILL.md](.trae/skills/polaroid-diary/SKILL.md) 复制到该目录

## 使用方法

在 Trae 中上传一张图片，然后说：

```
"用 polaroid-diary 生成拍立得日记"
"帮我生成这张照片的特写四宫格"
"生成拍立得风格的局部特写手账"
```

Skill 会自动：
1. 分析图片，选择4个有景别差异的特写部位
2. 为每个特写设计极简呼应的手绘涂鸦（耳朵自动生成招牌时钟）
3. 统一柔和低饱和度色调调色
4. 生成整齐对齐的2乘2四宫格拍立得排版

### 招牌效果：耳朵时钟

耳朵特写会自动在耳朵轮廓范围内绘制钟面：中心转轴点、时针分针、12/3/6/9数字、耳圈小点，利用耳朵本身形状作为钟面，不超出耳朵区域。

### 涂鸦规范：极简原则

涂鸦只作为画龙点睛的点缀，每张不超过3个元素，留白占90%以上：
- 眼睛：左右各一个四角星 + 下眼睑一排小圆点，无其他线条
- 嘴唇：嘴角一个极小空心心形，无猫须
- 手部：顺一根手指一条带箭头长线
- 腿部：顺两条腿各一条长线末端箭头指向袜子口
- 颈部：角落一个小月牙 + 项链旁一条短弧线带星

### 特写部位优先级

| 人像 | 物体/场景 |
|------|-----------|
| 眼睛（睫毛、眼神光） | 材质纹理（织物、木纹） |
| 手部（手指、手势） | 小物件（杯子、书籍、花） |
| 耳朵（发丝环绕、耳钉） | 光影细节 |
| 脚踝/手腕（袜子、饰品、鞋子） | 手与物的互动 |
| 嘴唇（唇色、表情） | |
| 发丝/颈部/锁骨/项链 | |

## 核心美学原则

- 色彩：柔和低饱和度撕拉片色调，肤色自然干净，禁止浓重复古黄
- 涂鸦：极度精简，点到为止，90%留白，细奶白色线条，逻辑呼应，禁止满脸连线
- 字体：真实自然铅笔潦草手写，有连笔有大小变化，禁止儿童笨拙，禁止完美花体
- 背景：纯白色纸张纹理，禁止米色、淡黄色、奶油色
- 排版：严格横平竖直对齐，边框无旋转，单张内容可带自然角度
- 景别：四个特写有明显景别差异，形成节奏
- 阴影：极淡柔和阴影或平贴，禁止浓重深色投影
- 氛围：安静、亲密、柔和、慵懒的私人日记感

## 注意事项

- 建议使用光线柔和的照片效果最佳
- 人像照片建议面部清晰可见，便于提取细节
- 输出为正方形高清图，适合社交媒体分享
