# Polaroid Close-up Extractor

> 一个 Trae AI Skill，从照片中提取人物/物体的局部特写，生成淡雅温暖的四宫格拍立得图文海报

##  功能特点

- **智能特写提取**：自动识别人像的眼睛、嘴唇、耳朵、手部、脚踝等细节部位
- **手绘涂鸦呼应**：每个特写搭配主题相关的白色铅笔手绘线条（眼睛配星芒、耳朵配时钟等）
- **复古拍立得质感**： authentic 拍立得边框、做旧泛黄效果、胶片颗粒感
- **手写英文诗句**：底部边框自然铅笔手写英文碎片文字
- **暖色调统一**：淡雅温暖的米色/奶油色调，轻松慵懒的午后氛围
- **自然排版**：每张拍立得轻微随机旋转，柔和阴影，纸张纹理背景

##  安装

### 方式一：直接复制到项目

```bash
# 进入你的项目目录
cd your-project

# 创建 skills 目录（如果不存在）
mkdir -p .trae/skills

# 克隆并复制 skill
git clone https://github.com/1NWZ/polaroid-closeup-extractor.git
cp -r polaroid-closeup-extractor/.trae/skills/polaroid-closeup-extractor/ .trae/skills/

# 清理临时文件
rm -rf polaroid-closeup-extractor
```

### 方式二：手动添加

1. 在你的项目中创建目录 `.trae/skills/polaroid-closeup-extractor/`
2. 将本仓库的 [SKILL.md](.trae/skills/polaroid-closeup-extractor/SKILL.md) 复制到该目录

##  使用方法

在 Trae 中上传一张图片，然后说：

```
"用 polaroid-closeup-extractor 生成拍立得海报"
"帮我生成这张照片的特写四宫格"
"生成拍立得风格的局部特写"
```

Skill 会自动：
1. 分析图片，选择 4 个最有表现力的特写部位
2. 为每个特写设计呼应主题的手绘涂鸦
3. 统一暖色调调色
4. 生成 2×2 四宫格拍立得排版

##  核心美学原则

- **色彩**：米色、奶油色、暖灰褐、灰粉色、柔和陶土色，禁用纯白/高饱和色
- **线条**：速写感、不完美、手绘铅笔质感，禁用干净矢量线
- **氛围**：轻松、慵懒、亲密、私密感，像午后翻阅私人相册
- **质感**：胶片颗粒、轻微暗角、柔焦边缘、复古纹理

## 📝 注意事项

- 建议使用光线柔和、色调温暖的照片效果最佳
- 人像照片建议面部清晰可见，便于提取细节
- 输出为正方形高清图，适合社交媒体分享
